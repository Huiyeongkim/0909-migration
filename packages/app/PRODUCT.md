# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

모바일과 데스크톱에서 공동구매 상품을 탐색하고, 장바구니·주문·로컬 포인트 결제를 처리하는 한국어 사용 구매자.

## Product Purpose

여러 사람이 함께 구매하는 상품을 한곳에서 발견하고, 공동구매 조건과 가격을 이해한 뒤 주문과 결제까지 완료하게 한다. 성공은 사용자가 현재 구매 가능한 항목과 다음 행동을 빠르게 파악하는 것이다.

## Operating Context

- 사용자는 공동구매 목록에서 가격, 상태, 참여 수량과 기간을 비교한다.
- 상세에서 원상품 정보, 수량과 배송 정보를 확인하고 장바구니 또는 바로 주문을 선택한다.
- 로그인 후 장바구니, 주문, 포인트 충전·결제와 취소를 사용한다.
- 같은 React 애플리케이션이 브라우저와 Tauri 데스크톱 셸에서 실행된다.

## Capabilities and Constraints

- 회원가입과 아이디·비밀번호 로그인
- 공동구매 목록·상세와 연결 상품 조회
- 장바구니 추가·수정·삭제
- 주문 생성·조회·포인트 결제·취소
- 로컬 개발용 포인트 충전
- 백엔드 API 계약과 현재 사용자 흐름은 이번 디자인 작업에서 변경하지 않는다.
- 현재 생성 API의 공동구매는 `SCHEDULED` 상태로 시작한다.

## Brand Commitments

- 제품명은 `0909 Commerce`이며 화면 언어는 한국어다.
- 사용자가 요청한 시각적 기준은 무신사에서 연상되는 상품 중심 편집 감각이다. 특정 화면이나 자산을 복제하지 않고 흑백 대비, 강한 타이포그래피와 밀도 높은 상품 정보를 독자적으로 해석한다.

## Evidence on Hand

- 실제 동작하는 로컬 Rust API와 PostgreSQL 인증 저장소
- 화면 검수용 상품·공동구매 6개
- 웹과 Tauri에서 공유하는 React 구현
- 실제 브랜드 로고, 제품 사진, 고객 후기와 운영 지표는 제공되지 않았다. 이를 임의로 주장하거나 조작하지 않는다.

## Product Principles

- 상품과 거래 조건이 장식보다 먼저 읽혀야 한다.
- 현재 상태와 가능한 다음 행동을 숨기지 않는다.
- 모바일에서도 가격·진행·마감 정보를 한눈에 비교할 수 있어야 한다.
- 웹과 데스크톱은 같은 정보 구조와 상호작용 언어를 사용한다.
- 비어 있음, 로딩과 오류도 완성된 제품 경험으로 다룬다.

## Accessibility & Inclusion

키보드 탐색, 명확한 포커스, 충분한 대비, 의미 있는 상태 텍스트와 축소 모션 설정을 유지한다.
